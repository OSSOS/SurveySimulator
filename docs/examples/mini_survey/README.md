# Mini survey example

A two-block OSSOS sample (`2013AE`, `2013AO`) for learning characterization
layout and for a quick `GetSurvey` smoke test.

## Files

- `pointings.list` — pointing history for the two blocks
- `2013AE.eff` / `2013AO.eff` — efficiency functions (small in-repo copies)

See [`../../README.formats`](../../README.formats) for the block file format.

Full survey packages (including complete OSSOS-MA) are distributed separately
in [`SurveySimulator-Data`](../../../../SurveySimulator-Data/).
